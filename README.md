# 마이크로비트 AI 자세 알리미 · 2편

Teachable Machine **이미지 모델**의 `good` / `bad` 판정을 웹캠에서 실행하고, 결과를 USB 시리얼로 micro:bit에 전송하는 수업용 웹앱입니다. 이 프로젝트에는 micro:bit 수신 코드나 HEX 파일이 포함되지 않습니다. 수신 코드는 직접 작성해 주세요.

## 준비물

- Teachable Machine 이미지 프로젝트와 공개된 모델 주소
- 카메라가 있는 컴퓨터, micro:bit, 데이터 통신 USB 케이블
- Web Serial 및 카메라 권한을 지원하는 Chrome 또는 Edge
- HTTPS 또는 localhost 접속, 인터넷 연결

## 사용 방법

1. micro:bit 수신 코드에서 한 줄씩 읽고 `good` 또는 `bad`를 처리하도록 준비합니다.
2. Home에서 USB 연결을 누르고 포트를 선택합니다. 이 화면의 `good 보내기` / `bad 보내기` 버튼으로 먼저 연결을 확인합니다.
3. AI 자세 인식 화면에서 Teachable Machine 모델 폴더 주소를 입력하고 **모델 확인**을 누릅니다.
4. 모델 class에 `good`과 `bad`가 각각 하나씩 있어야 합니다. 빈 화면이나 다른 사람을 거르는 별도 class를 추가하면 좋습니다.
5. 신뢰도 기준을 조정하고 micro:bit 연결 후 **카메라 시작**을 누릅니다. 카메라 권한을 허용하면 예측이 시작됩니다. 권한 오류가 나오면 주소창의 카메라 권한에서 허용을 선택한 뒤 다시 시작합니다.
6. 끝나면 카메라 정지와 USB 연결 해제를 누릅니다. 카메라를 멈추거나 모델을 바꾸면 화면의 현재 class와 신뢰도는 초기화됩니다.

## 판정 및 전송

기본 신뢰도는 90%입니다. 표시 신뢰도는 정수로 반올림하지만, 전송 여부는 반올림 전 확률로 비교합니다. 따라서 실제 확률이 89.5%이고 기준값이 90%이면 화면에 90%로 표시되어도 전송하지 않습니다. 동일 class가 600ms 이상 유지되고 원래 확률이 기준값에 도달하면 전송합니다. 같은 class의 반복 전송은 1.5초 간격으로 제한합니다. `good` 또는 `bad` 외 class, 신뢰도 기준 미달, 판정 불안정 상태는 전송하지 않습니다.

USB 전송은 115200 baud이며 UTF-8 한 줄 명령 `good\n` 또는 `bad\n`만 사용합니다. MakeCode 수신 쪽에서도 줄 단위로 읽어 처리해 주세요. 수신이 끊기면 경보를 끄는 타임아웃 처리는 micro:bit 코드에서 구현하는 것이 좋습니다.

## 개인정보와 모델 안내

웹캠 영상과 프레임은 브라우저에서만 사용하며 앱 서버로 전송하거나 저장하지 않습니다. Teachable Machine 모델 파일과 TensorFlow 라이브러리는 외부 CDN에서 불러오므로 인터넷 연결이 필요합니다. 이 모델은 관절 위치나 의학적 자세를 진단하지 않습니다. 학습한 카메라 각도, 거리, 조명에 따른 이미지 분류 결과입니다.

## 실행과 검증

```bash
npm install
npm run dev
npm test
npm run lint
npm run build
```

개발 주소는 `http://127.0.0.1:5173/microbit-ai-project2/`입니다. 로컬 하드웨어를 연결하지 않는 테스트는 브라우저/카메라 권한과 실제 micro:bit 수신을 검증하지 않습니다.
